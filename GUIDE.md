## How to Run

### Local (CMD/Terminal)
1. Clone the repo:
   git clone https://github.com/Veri-ai/api-testing-python.git
   cd api-testing-python

2. Install dependencies:
   pip install -r requirements.txt

3. Run the basic script:
   python apiTest.py

4. Or run the pytest version for clean reports:
   pytest -v

### Online (No Local Setup)
- **GitHub Codespaces**: Open the repo in Codespaces and run the same commands above.
- **Replit**: Copy files into [Replit](https://replit.com/) and run directly in the browser.
